# EXPLICACIÓN DE LO QUE HACE EL PROYECTO

En este proyecto se ha realizado una página web en la que hay un formulario para añadir un libro a la izquierda, una vez añadido un libro aparece a la derecha y se va creando una lista de libros.
Cuando se hace click sobre uno de los libros en la lista se modifica como que el libro ha sido leído, y aparece a la derecha la fecha en la que se a hecho click sobre el libro.
Debajo de la lista de libros hay un contador de cuantos libros hay y cuantos has marcado como leídos.
